# IoT-Based Hybrid Solar and Wind Power Plant Monitoring System

## Overview

This project is an IoT-based Hybrid Solar and Wind Power Plant Monitoring and Control System developed using ESP32. The system continuously monitors solar panel voltage, wind turbine voltage, battery voltage, charging current, load current, temperature, and humidity through multiple sensors and displays the information on a responsive web dashboard.

The dashboard provides real-time monitoring, relay control, scheduling, and protection limit configuration through any web browser connected to the same network. The system is designed for renewable energy management, smart energy monitoring, and remote control applications.
